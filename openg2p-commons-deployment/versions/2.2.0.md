### Release notes

Stable version; includes consent management, partner management

### Summary

- **Major:** Consent Manager (CM) enabled by default, with version bump and new E2E sanity toggle added to questions.yaml; APIs renamed to <release>-cm-api and -cm-partner-api, requiring adjustments to base URLs.
- AWE token validation fixed by pointing the openg2p-awe issuer to the EXTERNAL Keycloak issuer, resolving previous validation errors; AWE repository and version updated.
- Migration of multiple components (Master Data, AWE, Audit Manager, PM, and CM) to GitLab, with Helm charts now referenced from the GitLab Helm repository.
- Improvements made to uninstall scripts and fixes applied to pre-commit checks and incorrect chart paths.
